# Challenge brief

The brief `challenge` gives to both `architect` and `product-manager`. Both agents get the same brief.

## Fields

- **Plan text**: the full draft plan (project, epic, feature or ticket list), pasted as text. Never a vault path or note link.
- **Repo path**: absolute path to the repository the plan targets, so the agents can read the code read-only.
- **Project rules (optional)**: project rules or limits that apply beyond the defaults (for example a `CLAUDE.md` excerpt), pasted as text.

## Note for the agents

Engineers later get only tickets that pass this challenge, so raise anything that would block them now.
